# Rationale for go-gitea/gitea@a1cc65126711

## GOAL

Fix resolution and proxying of `<source>` `srcset` links and correctly wrap `<picture>` elements with links.[^1], [^2], [^3]

## NEED

The post-processor did not rewrite `<source>` nodes, so relative `srcset` links could resolve to the HTML file view instead of the media route.[^4], [^5] With Camo enabled, an unrewritten `<source>` candidate could make readers’ browsers contact an external host directly.[^6]

## ALTERNATIVE

Review suggested `strings.Fields` or `strings.FieldsSeq`, but the parser needed to handle additional details those approaches could not.[^7], [^8], [^9]
