# Rationale for go-gitea/gitea@a1cc65126711

## GOAL

Resolve and proxy `srcset` links on `<source>` elements, use correct links for picture source `srcset` attributes, and wrap the picture element with a link correctly.[^1], [^2], [^3]

## NEED

The post-processor did not visit `<source>` nodes, so relative `srcset` links could resolve against the page URL instead of the media route; with camo enabled, source candidates could also bypass the proxy.[^4], [^5], [^6]

## ALTERNATIVE

A review suggested `strings.Fields` or `strings.FieldsSeq`; the parser was reworked around `strings.FieldsSeq`, but review noted that `strings.Fields` could not handle all the parser details.[^7], [^8], [^9], [^10]
