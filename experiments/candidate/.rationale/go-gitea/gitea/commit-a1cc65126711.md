# Rationale for go-gitea/gitea@a1cc65126711

## GOAL

The change aims to resolve and proxy `srcset` links on `<source>` elements and wrap the `<picture>` element correctly.[^1], [^2] The `source` visitor should apply the same link resolution and camo handling as for `img` and `video`, while preserving candidates and descriptors.[^3]

## NEED

The post-processor visited `img` and `video`, but not `<source>`, leaving its `srcset` unrevised.[^4] As a result, a relative `srcset` could resolve against the page URL instead of the media route, preventing the dark image from loading.[^5] With camo enabled, an unrevised `<source>` could send a reader’s browser directly to an external host, exposing their address and user agent.[^6]

## ALTERNATIVE

A reviewer suggested using `strings.Fields` or `strings.FieldsSeq` and cautioned against reinventing the wheel.[^7], [^8] The author reworked the parser around `strings.FieldsSeq`, treating fields as candidate URLs or descriptors and using edge commas to separate candidates while preserving embedded commas.[^9] The reviewer later said `strings.Fields` could not handle the parser’s details.[^10]
