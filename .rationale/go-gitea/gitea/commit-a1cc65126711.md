# Rationale for go-gitea/gitea@a1cc65126711

## GOAL

Resolve and proxy `srcset` links on `<source>` elements, use correct links for picture source `srcset` attributes, and wrap the `<picture>` element with a link correctly.[^1], [^2], [^3] The new `source` visitor sends each `srcset` candidate through the same link resolution and camo handling as `img` and `video`, preserving separators and descriptors in multi-candidate lists.[^4]

## NEED

The post-processor visited `img` and `video` nodes but not `<source>`, so relative `srcset` links resolved against the page URL and landed on the HTML file view instead of the media route.[^5], [^6] With camo enabled, an unrewritten `<source>` candidate could send readers’ browsers directly to an attacker’s host.[^7]

No evidence found.
